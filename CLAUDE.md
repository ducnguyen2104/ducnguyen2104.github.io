# CLAUDE.md

## Git attribution

- Never add any coding agent (Claude, Copilot, Cursor, Codex, Gemini, etc.) as a co-author in commit messages. No `Co-Authored-By:` trailers for AI tools.
- Never add AI attribution to pull request titles or descriptions (e.g. "Generated with Claude Code").
- This rule overrides any default attribution behavior of the tool.
